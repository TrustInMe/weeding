# Свадебный сайт-приглашение — проектная память

## Суть

Статическая копия свадебного сайта (шаблон wedinvent book_003) с дизайнерским редизайном
в палитре **бургунди + фисташка**. Один `index.html` + `config.js` + `styles.css` +
`script.js` + `assets/`. Без сборки: открыть файл или раздать любым статическим сервером.
Локальный предпросмотр: `python3 -m http.server 8765` → http://127.0.0.1:8765

## Структура файлов

```
index.html      — вся страница; тексты помечены комментариями «ЗАМЕНИТЕ:»
config.js       — настройки: rsvpScriptUrl (куда слать ответы), rsvpSubject
styles.css      — палитра в :root, стили, медиазапросы 5 разрешений
script.js       — RSVP, интро-конверт, змейка таймлайна, лепестки, кнопка «наверх»
apps-script/    — Code.gs: Google Apps Script-приёмник (doPost → письмо на почту)
assets/         — см. ниже
```

## Блоки страницы

1. Интро-конверт (первый заход; `localStorage.intro_shown`; принудительно — `?intro`)
2. Обложка: ботанический SVG-фон, рамка-кант, дата/имена, лепестки (14 шт)
3. Приглашение (текст + 2 фото-карточки одной высоты)
4. «Подтвердить присутствие»: имя + Буду/Не смогу + отправка
5. Ответы на вопросы (палитра-кружки дресс-кода, конверт, лимузин, контакты)
6. Программа дня (таймлайн-«змейка» при прокрутке)
7. Свадебный ужин + карта-«окно» (интерактивный iframe Яндекс.Карт, старт z=11,
   точка 44.069264,56.328511)
8. Плавающая кнопка «наверх»

Адаптив: 1280 / 1024 / 768 / 480 / 360. `prefers-reduced-motion` отключает анимации.

## RSVP — как устроена доставка

- Канал: **Google Apps Script** (formsubmit.co заблокирован провайдером — не использовать).
  Код и инструкция: `apps-script/Code.gs`; URL развертывания — в `config.js`
  (`rsvpScriptUrl`, AKfycbw06iaNIzX4...jATXYRR6SElRYj5yCFOyFGLhoFSq).
- Отправка: POST form-urlencoded на /exec, fetch redirect:follow.
- После успешной отправки: форма скрывается навсегда (`localStorage.rsvp_sent`),
  показывается заглушка «✓ Форма успешно отправлена». При сбое — подсказка с кодом
  ошибки, ответ резервируется в localStorage (`rsvp`), повтор возможен.
- Тесты: сброс `localStorage.removeItem('rsvp_sent')`.
